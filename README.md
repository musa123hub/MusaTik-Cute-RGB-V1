## 💖 About MusaTik

**MusaTik Cute RGB V1** হলো একটি সুন্দর, কিউট এবং RGB-style web project।

এখানে modern dark UI, RGB glow, TikTok URL input এবং Node.js backend structure রাখা হয়েছে।

---

## ✨ Features

- 🌈 Cute RGB UI
- 🎨 RGB Hue Control
- 💡 RGB Glow Control
- 🔴 RGB ON / OFF
- 📋 Paste Button
- 🔗 TikTok URL Validation
- 📱 Mobile Responsive Design
- ⚡ Node.js Backend
- 🚀 Express Server
- 💬 Success / Error Message
- ⏳ Loading Animation
- 📊 Animated Statistics
- ❓ FAQ Section
- ⌨️ Keyboard Shortcut
- 🛡️ Basic Security Headers
